# Study Notes

## AOI

Automated Optical Inspection uses imaging to detect visible assembly defects.

Typical quality concerns include:
- defect coverage
- false calls
- repeatability
- recipe setup
- traceability

## SPI

Solder Paste Inspection checks printed solder-paste condition before component placement / reflow.

## False Positive / False Call

A good unit incorrectly flagged as defective.

Excessive false calls can increase manual verification and rework burden.

## CI/CD

Continuous Integration / Continuous Delivery automates checking and integration of code changes.

In manufacturing analytics, the same principle can be used to validate changes to engineering scripts.

## RAG

Retrieval-Augmented Generation retrieves relevant enterprise documents before generating an answer.

Its value in a quality context is grounded access to controlled internal knowledge rather than generic model memory.

## OCAP

Out-of-Control Action Plan.

A predefined response workflow used when process or quality indicators move outside an allowed state.

## CAPA / 8D

Structured corrective and preventive action methods used to identify root cause, implement fixes, and prevent recurrence.

## Human-in-the-Loop

A system in which AI supports decision-making while a qualified person reviews or approves actions.
