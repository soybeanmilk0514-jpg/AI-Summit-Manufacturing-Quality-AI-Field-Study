# 02. Delvitech / KAIS — HORUS

## What I Saw

현장에서 가장 인상 깊었던 장비는 Delvitech의 **HORUS AI 3D inspection platform**이었다.

국내 전시에서는 KAIS가 Delvitech 솔루션을 소개했다.

HORUS는 SMT / PCB production을 대상으로:

- 3D SPI
- pre-reflow AOI
- post-reflow AOI
- AI-based defect classification
- 3D optical inspection

을 하나의 platform에서 다루는 방향의 장비다.

## Why This Was Relevant to Quality Management

검사 자동화의 핵심은 단순히 defect를 한 번 찾는 것이 아니라:

- false positive를 줄이고
- 검사 rule / recipe를 반복 가능하게 만들고
- line expansion 시 동일 품질을 유지하며
- manual verification 부담을 낮추는 것

이라고 이해했다.

## Transferable Semiconductor Insight

HORUS 자체는 wafer front-end inspection tool이 아니다.

하지만 품질관리 관점에서 다음 logic은 semiconductor manufacturing에도 그대로 중요한 개념이다.

```text
Acquire image / measurement
        ↓
Classify anomaly
        ↓
Separate true defect from false call
        ↓
Record traceable result
        ↓
Feed result back to process
```

## Career Relevance

품질 직무에서는 defect detection rate만큼이나 false call, repeatability, recipe consistency, traceability가 중요할 수 있다.

양산기술에서는 inspection result를 process condition change와 연결해 원인을 좁히는 능력이 중요하다.

이번 장비 demo를 통해 **AI inspection도 결국 process-control loop의 한 부분**이라는 관점을 얻었다.
